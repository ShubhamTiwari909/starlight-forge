# Starlight fixture

This is a content and configuration example, not a complete standalone package. To try it, scaffold a disposable Astro + Starlight project using the current official instructions in [Starlight Getting Started](https://starlight.astro.build/getting-started/), then copy `astro.config.mjs` and `src/content/docs/` into it. Follow the generated project's scripts and dependencies. No dependency versions are pinned here.
